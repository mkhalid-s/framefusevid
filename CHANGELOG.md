## [0.1.0] - 2024-12-05

### Added
- Initial release of FrameFuseVid
- Multi-view Zoom file detection and auto-recognition
- Picture-in-Picture (PIP) layout with drag-and-drop positioning
- Side-by-Side layout for split-screen videos
- Sequential layout for consecutive playback
- Audio Merge layout to replace video audio tracks
- Interactive drag-and-drop overlay positioning
- Live preview with video thumbnails
- VTT/SRT caption burning to video
- Quality presets (Fast/Medium/Slow)
- Cross-platform builds (macOS, Windows, Linux)
- Dark/Light theme support
- One-click folder scanning for Zoom files
- Adjustable overlay size (10% to 50%)
- Preset positions (corners) and custom placement

### Features
- **Privacy-First**: All processing happens locally on your machine
- **Zoom Intelligent Detection**: Automatically recognizes Zoom file naming conventions
- **Professional Output**: Create broadcast-quality videos with ease
- **Offline Operation**: Works completely without internet connection
- **Free and Open Source**: MIT License

### Technical Stack
- Electron 28 for cross-platform desktop application
- React 18 for user interface
- Tailwind CSS 3 for styling
- FFmpeg for video processing
- electron-builder for application packaging
