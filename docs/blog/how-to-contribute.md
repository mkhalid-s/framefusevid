# How to Contribute to FrameFuseVid

*February 16, 2026 · 4 min read*

Open source is at the heart of FrameFuseVid. Whether you are a developer, designer, or user, here is how you can help.

## Development Setup

```bash
git clone https://github.com/YOUR_USERNAME/framefusevid.git
cd framefusevid
npm install
npm run dev
```

The app uses Electron 40, React 18, Tailwind CSS, and Vite.

## Ways to Contribute

1. **Report Bugs** — open a GitHub issue with OS, Node version, and reproduction steps
2. **Request Features** — open a discussion or feature request issue
3. **Submit Pull Requests** — create a feature branch, make changes, open a PR
4. **Improve Documentation** — PRs to the `docs/` directory auto-deploy
5. **Test on Your Platform** — edge cases and platform-specific issues are valuable

## Code Style

- ES6+ features, functional React with hooks
- Meaningful names, comments for complex logic only
- Components under ~300 lines

This project follows a Contributor Code of Conduct. By participating you agree to abide by its terms.
